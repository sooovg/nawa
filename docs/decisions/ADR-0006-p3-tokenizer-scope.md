# ADR-0006: Tokenizer work before a licensed corpus exists (P3-01/P3-02 code-only, P3-03 blocked)

- **Status:** ACCEPTED (owner instruction of 2026-10-01, 08:50 +03: "merge PR #22 and start P3-01 and P3-02"). Proposed
  by agent P3-01/02. Applies ROADMAP §0 the same way ADR-0005 does for P2. No goal, gate, target, or task ID changes.
- **Date:** 2026-10-01
- **Task:** P3-01, P3-02

## Context

1. Earlier reports (P3-04, P3-06, P3-08) said P3-01..P3-03 need a licensed Arabic corpus and so wait for P2/G2.
2. That is true for the **choice** (P3-03: "choose the tokenizer by measurement and record an ADR"): a choice made on
   synthetic text would fix the vocabulary of every later model on evidence that does not describe real Arabic.
3. It is not true for the **candidates and the measurement harness** (P3-01, P3-02). They are code and tests, like the P2
   tools in ADR-0005: they can be built and checked on code-generated text, ingest no external data, and decide nothing.

## Decision

- **D1.** Split the status row `P3-01..P3-03` into three rows. No ID changes.
- **D2.** P3-01 and P3-02 run now, code only: tokenizers written from scratch (Track S; no external tokenizer library or
  vocabulary), trained and measured on text generated by `src/nawa/tokenizer/corpus.py`. No external corpus, no frozen
  data, no upload.
- **D3.** P3-03 is **BLOCKED** until a licensed real corpus exists (OD-03 and the P2 data tasks). The P3-02 report states
  "selection: none", and the reference core keeps `vocab_size=256` (byte level) until P3-03.
- **D4.** Correctness criteria (exact round-trip, deterministic training, save/load identity, vocabulary within target,
  learned candidates compress better than bytes) are pass/fail. Comparative numbers are recorded as evidence for P3-03,
  not as a ranking.

## Consequences

- G3 keeps all its conditions. It cannot close before P3-03.
- When a licensed corpus exists, P3-03 re-runs the same harness on it (the generators are replaced by real held-out sets)
  and records the choice in a new ADR.

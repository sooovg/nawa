# NAWA — Native Arabic Weighted Architecture

**نوى:** النواة أو الأصل الذي تُبنى حوله القدرات.

NAWA مشروع لبناء نظام ذكاء اصطناعي عربي أولًا، صغير نسبيًا، موثوق وقابل للتدقيق وإعادة الإنتاج. NAWA نظام متكامل وليس ملف أوزان منفردًا (انظر `ARCHITECTURE.md`).

> **الحالة:** مرحلة التأسيس (P0). **لم يعلن المشروع أي نتائج بعد.** لا يوجد نموذج مدرَّب، ولا baseline مقاس، ولا أي ادعاء أداء. أي رقم يظهر لاحقًا لا يُعتد به إلا إذا كان مسجلًا في `docs/claims.md` بالصيغة المحددة في `ROADMAP.md` (القسم 9).

## فصل Git عن Hugging Face

| المكان | ما يحتويه |
|---|---|
| **Git** (هذا المستودع) | الكود، الاختبارات، الوثائق وADRs، الإعدادات الصغيرة، السكربتات، سجل الحالة والتجارب، وmanifests/hashes تشير إلى HF. |
| **Hugging Face** | الأوزان، الـ adapters، البيانات، النسخ المضغوطة، وبقية artifacts التدريب، في مستودعات **خاصة** حتى بوابة الإصدار. |

- لا أوزان ولا بيانات كبيرة ولا أسرار في Git. الحد الافتراضي لحجم الملف في Git هو 5MB.
- عناوين مستودعات HF مسجلة في [`configs/hf_repos.yaml`](configs/hf_repos.yaml).
- لا يُستخدم HF للتطوير النشط، ولا بديلًا عن مراجعة Git.

## الأوامر

```bash
make setup   # تثبيت بيئة التطوير (pytest, pyyaml, pre-commit, detect-secrets)
make test    # اختبارات التأسيس
make ci      # ما يشغله CI: الاختبارات + فحص الأسرار
```

الأوامر الأخرى المذكورة في `AGENTS.md` (مثل `make train` و`make eval`) موجودة الآن كأهداف ترفض التنفيذ عمدًا حتى تُنجز مهامها في الخارطة.
